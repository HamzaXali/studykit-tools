Organising study notes with tags

Study guide · Updated 28 October 2026

Notes pile up quickly across lectures, labs and readings. A lightweight tagging system — week, topic, module code — makes retrieval faster than scrolling endless documents, especially before exams.

Choose a small tag set

Start with a few tags you will actually reuse: module code, week number and topic keywords.
