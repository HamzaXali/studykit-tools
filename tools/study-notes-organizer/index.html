Study notes organiser

Keep revision notes, reading summaries and lesson ideas in one place, sorted by tag, without creating an account.

Your notes are stored only in this browser on this device.They are not uploaded and do not sync to your other devices. Clearing your browser data, using a private window, or switching browser will remove them or hide them. Export a backup regularly.

This browser is blocking storage.Notes will work for this visit only. Export them before you close the tab.

Add a note

Separate tags with commas, for example: biology, exam, chapter 3

Your notes

Searches titles, text and tags. Accents are ignored.

    Back up, move or delete notes

    JSON files can be imported again here, in this or another browser. Markdown and plain text are for reading, printing or pasting elsewhere.

    Imported notes are added to your current notes. If the same note exists in both, the most recently edited copy is kept.

    How to use the notes organiser

    1. Give the note a title, write the note, and add a few tags such as the subject and the exam it is for.
    2. Choose Save note. The note appears in Your notes, newest first.
    3. Find notes later by typing in Search notes or picking a tag from Show tag.
    4. Choose Edit on a note to change it, or Delete to remove it. You will be asked to confirm before anything is deleted.
    5. Choose Export JSON backup now and then, and keep the file somewhere safe, such as your school drive.

    Worked example: organising revision by tag

    Create three notes:

    • “Cell structure” with the tags biology, unit 1
    • “Enzymes” with the tags biology, unit 2
    • “Moles and mass” with the tags chemistry, unit 1

    Choosing unit 1 in Show tag lists “Cell structure” and “Moles and mass”. Searching for enzyme finds the second note. Tags are stored in lowercase, so Biology and biology become the same tag.

    Moving notes to another device

    Export a JSON backup on the first device, send the file to yourself, then open this page on the second device and use Import a JSON backup.

    Questions and answers

    Can anyone else see my notes?
    Notes never leave your device through this site. Anyone who uses the same browser profile on the same device can open this page and see them, so do not store passwords or very private information here.
    How many notes can I keep?
    Browsers usually allow about 5 MB for this kind of storage, which is enough for thousands of typical notes. You will see a message if storage is full.
    Why did my notes disappear?
    Usually because browser data was cleared, a private or incognito window was used, or you are in a different browser or profile. Import your latest JSON backup to restore them.
