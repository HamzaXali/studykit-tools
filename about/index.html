About StudyKit Tools

StudyKit Tools is a small collection of free browser tools for students, teachers, writers and people who make education content. How the tools are built

  • Private by design. Text is processed by JavaScript in your browser. The site has no accounts, no analytics and no cookies, and the pages are set up to block connections to other servers.
  • Light and fast. Each page is plain HTML, CSS and a few small scripts, with no external fonts or libraries.
  • For many languages. Counting and case conversion use the browser's built-in Unicode support, so accents, emoji, Urdu, Arabic and Chinese text are handled properly.
  • Accessible. The tools are designed to work with a keyboard, a screen reader and on small screens.

Limits

The tools are for everyday convenience. Counts and time estimates follow the rules explained on each tool page and can differ slightly from other software. See the disclaimer.
