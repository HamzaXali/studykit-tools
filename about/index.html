About StudyKit Hub

StudyKit Hub is a free educational website for students, teachers and education creators. Its aim is simple: learn smarter, study better.

Who runs it

StudyKit Hub is an independent project run by Ali Hamza in Pakistan. It is not affiliated with any school, university, exam board or other organisation.

What is available now

Six free study tools that work in your browser: a study notes organiser, a word and character counter, a reading time calculator, a case converter, a whitespace cleaner and a duplicate line remover.

What is planned

Study guides, revision notes and worksheets are planned but not yet available. They will be published only when there is genuinely useful, original material to share, so there are no dates yet.

How the tools are built

  • Private by design. Text is processed by JavaScript in your browser. The site has no accounts, no analytics and no cookies, and the pages are set up to block connections to other servers.
  • Light and fast. Each page is plain HTML, CSS and a few small scripts, with no external fonts or libraries.
  • For many languages. Counting and case conversion use the browser's built-in Unicode support, so accents, emoji, Urdu, Arabic and Chinese text are handled properly.
  • Built for accessibility. The tools are built to work with a keyboard, with assistive technology and on small screens. They are checked with automated accessibility tests and keyboard testing, but not yet with every screen reader, so please tell us if something does not work for you.

Limits

The tools are for everyday convenience. Counts and time estimates follow the rules explained on each tool page and can differ slightly from other software. See the disclaimer.
